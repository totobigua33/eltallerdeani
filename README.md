# Atelier Costura - sitio web de cursos

Sitio responsive listo para publicar como demostración en GitHub Pages, Netlify o Vercel.

## Personalización rápida

1. Abrí `index.html` y cambiá `Atelier Costura`, el email y los textos.
2. Abrí `app.js`:
   - Reemplazá `5493329000000` por tu WhatsApp con código de país y sin símbolos.
   - Editá los cursos del bloque `courses`: título, nivel, precio, descripción e imagen.
3. Reemplazá las imágenes remotas por fotos propias cuando las tengas.

## Publicación en GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html`, `styles.css` y `app.js` a la raíz.
3. En Settings > Pages, elegí Deploy from a branch y la rama `main`.

## Para vender y proteger los videos de verdad

La web incluida es el frente comercial y usa WhatsApp como compra inicial. Para automatizar pagos y acceso privado se recomienda:

- Pagos: Mercado Pago Checkout Pro.
- Videos protegidos: Vimeo, Bunny Stream o YouTube no listado como solución inicial.
- Área de alumnas: WordPress + WooCommerce + Tutor LMS / LearnDash, o desarrollo con Supabase.
- Dominio propio y correo profesional.

No conviene cargar archivos MP4 directamente en GitHub: no protege el contenido y puede superar fácilmente sus límites. Para producción, insertá videos alojados en una plataforma con control de acceso.
